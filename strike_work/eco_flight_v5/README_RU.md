# Eco Threat · Flight TEST v5

После сброса нажать Start в главном меню. Кампания помечена как CAMPAIGN #10, ниже ECO THREAT. Запускается последовательность Movie → Brief 6 с музыкальной командой первой сцены Brief 2. Заставку можно пропустить. Номер SOUND поднят на две тайловые строки.

В полёте на шестикнопочном джойстике Z завершает очередное задание через штатный обработчик Jungle Strike. Удержание засчитывается один раз. Сборка с --without-debug-z исключает вызов отладочного обработчика. Данные открытия объектов при этом остаются частью уровня.

Добавлены 13 статических объектов из DOS, включая семь строений Ice Station, снежные холмы и занесённые снегом домики. Холм №6 открывается при завершении четвёртого задания. Это этап расстановки. Разрушение, выдача предметов, спасение людей и противники для этих объектов ещё не перенесены. Использованы аналоги графики из Genesis Snow Fortress.

При прокрутке движок дополнительно перерисовывает видимую часть площадки №42. Проверка использует RAM и VRAM из сейва Kega Fusion версии v4. Стартовая камера Eco Threat начинает внутри карты. Игровая позиция вертолёта берётся из DOS.

Репозиторий содержит сборщик и IPS. Для самостоятельной сборки нужны v4, DOS LEVELA, данные предыдущих этапов и vasmm68k_mot. Запуск из корня проекта: python strike_work/eco_flight_v5/build.py. IPS применяется к оригинальному ROM с SHA-1 7a7568e39341b1bb218280ee05c2b37c273317b5.
