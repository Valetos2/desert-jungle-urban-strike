# Jungle DOS — разведочная сборка v1

Оригинальный розничный CD JUNGLE.DAT определяется по SHA-256 в build_scout_dat.py. Скрипт перепаковывает только исполняемую запись и пересчитывает смещения. Все остальные байты ресурсов совпадают. Заголовок MZ и таблица релокаций после патча имеют прежний размер.

У штатного кода CHICKEN распознаватель в 2C10. Он активирует флаги 1F31/5590. У 5590 есть ветки пропуска расхода топлива и боезапаса, но исключение урона в штатном режиме зависит от ветки столкновения. Версия v1 использует отдельные перехваты. Код переключателя штатного чит-режима используется для перехватов двух входов урона C9C6 и C9F0. Перехваты проверяют идентификатор активной машины, до остальных объектов урон доходит. AFC3 возвращает топливо к максимуму. Путь 7EA8 пропускает списание только для активной машины, у остальных сохраняется исходная ветка. Значения читаются из активных структур, поэтому пароль не должен сбросить изменения в коде.

Для сборки: python strike_work/dos/build_scout_dat.py original/JUNGLE.DAT output/JUNGLE.DAT

Проверка в Unicorn: оригинальный x86-распаковщик загрузчика с подставленным DOS-чтением распаковал новый MZ байт в байт, в том числе на границах 32-килобайтных окон. Проверены отдельно оба входа урона на игроке и другой цели, расход боеприпасов у игрока и другой машины, восстановление топлива с 0, 1 и 99 до заданного максимума. Полный запуск игры и ввод пароля не проверены.

Вместимость 6 пока сохраняется. Условие подбора в 6526. Два буфера индексов объектов по 53FF и 540B пишутся в 6172 и 6189, выгружаются через 6945/69F8, а при смене транспорта сохраняются и восстанавливаются копированием по 6 слов в AC82–AC90 и ACF5–AD03. Рядом находятся данные специальной выгрузки 5417 и счётчики 541B/541D. Для увеличения вместимости требуется перенос буферов вместе с сохранённым состоянием транспорта или расширение формата. Новый DAT передаётся отдельно от репозитория.

## Scout v2 · клавиатура

Файл JUNGLE.EXE с диска запускает исполняемый ресурс внутри JUNGLE.DAT.
Начальные значения DS:1D9F..1DA6 заменены на 1E 20 11 1F 4B 51 50 4F.
Штатное меню заполняет колонку Old Key через 27AB/280E, подтверждение переносит восемь байт через 27CE, а опрос полётного управления идёт через 2A17..2A8B.
Профиль SCOUT2.CFG получает отдельное имя для совместной эксплуатации с оригиналом; v2 использует штатную запись и контрольную сумму и открывает конфигурацию на чтение. На CD встроенная раскладка работает без CFG. Иные прежние настройки отдельный профиль не импортирует.

При сборке v2 SHA-256 JUNGLE.DAT — 13344b5ea0b0152407032aca32bef33ffb9637a6cfb7be7fedc6ef1b96de8b63.
verify_scout.py принимает путь к собранному DAT. Проверены декодирование родным загрузчиком, подписи восьми клавиш штатным кодом меню, маска каждого действия при отдельном нажатии, изменение первой клавиши на Q и повторное чтение этой настройки другим экземпляром x86-эмулятора через оригинальные обработчики записи и загрузки CFG. Файловые вызовы DOS в тесте обслуживает память. Полный графический сеанс DOSBox не запускался.
