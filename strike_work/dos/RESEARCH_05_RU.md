# Jungle DOS и Genesis — команды объектов

У секторных записей обоих портов с +34 идёт список команд. Заголовок команды занимает два байта: код и длина полезных данных. После полезных данных следует следующая команда. Пара нулевых байтов завершает список. В DOS длина может быть нечётной. У многих пар Genesis использует длину, округлённую на один байт, с нулём в конце полезных данных.

Скрипт compare_object_commands.py прочитал списки всех 1245 записей, доступных через секторные таблицы DOS, включая 95 записей десятой миссии. Для 963 однозначных пар DOS/Genesis отдельно сверены флаги, адрес записи состояния и список команд.

| Сверенное поле | Совпадений из 963 пар |
|---|---:|
| 32-битные флаги по +12 с учётом порядка байтов | 963 |
| Индекс записи состояния после пересчёта адреса | 953 |
| Полностью совпавший список команд с учётом дополнения нечётной длины | 847 |

Во второй миссии совпали все три проверки у всех 118 пар. Все десять несовпадений индексов записи состояния относятся к седьмой миссии. Для пересчёта индекса DOS используется младшее слово адреса по +30, база CB80 и шаг 20 байт. В Genesis четырёхбайтовый адрес по +30 имеет базу FF391E и шаг 30 байт. Результат описывает найденное соответствие, включая исключения, и пока не используется для записи ROM.

В десятой миссии 52 команды у 23 записей: 45 с кодом 16, четыре с кодом 0E и три с кодом 02 (коды в шестнадцатеричной системе). У трёх записей frigate суммарно 11 команд. Они используют несколько форм полезных данных, а у awac найдена одна команда с кодом 16. По этим данным можно искать вызовы в обработчиках обычных миссий. Назначение отдельных операций, точные условия завершения и свойства погружения кораблей ещё требуют проверки.

Для повторной проверки из корня репозитория:

```sh
python strike_work/dos/compare_object_commands.py --input /path/to/unpacked/jungle --rom /path/to/original/jungle_strike.bin
```

Отчёт object_commands.json содержит количества, смещения, индексы записей состояния и формы команд десятой миссии. Полный список полезных данных строится локально из пользовательской копии игры.
