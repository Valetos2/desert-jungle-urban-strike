# Eco Threat — опыт преобразования графики

19 ноября 2026. Пробные варианты местности и трёх объектов. В ROM пока не подключены.

Запуск из корня проекта

```
python strike_work/dos/color_experiment/build_ntsc_preview.py gx
python strike_work/dos/color_experiment/preview.py
```

Нужны GCC, Pillow, NumPy, распакованные DOS-ресурсы и исходник md_ntsc из Genesis Plus GX. Обёртка C использует оригинальный NTSC composite preset Shay Green / EkeEke с собственным выводом строки. Исходники фильтра и его лицензия находятся в gx/core/ntsc, в этом каталоге они не дублируются.

RGB-превью использует нормализованную шкалу DAC TmEE (0, 52, 87, 116, 144, 172, 206, 255). NTSC-превью использует собственную цветовую модель исходного md_ntsc. Это два явно разных способа отображения одних кодов CRAM, возможные отличия между ними включают цветопередачу. PAL, реальная ЭЛТ, параметры конкретного кодера и телевизора не моделируются. Таблицы ниже описывают статичную графику. В игре ещё нужно проверить движение, перекрытия и распределение палитр между всеми объектами и интерфейсом.

AWAC кадр 0, TANK1 кадр 4 (широкая красная полоса), F217 кадр 0. Декодированы таблицы кадров, блоки 16×16 и сжатые маской группы из 8 пикселей. Границы сжатых блоков проверены по следующим указателям, для последнего допускается выравнивание до секции палитры. Исходный цвет 0 сохраняется прозрачным. На листах объект показан на чёрном фоне.

Для каждого объекта выбрана собственная палитра максимум 15 видимых цветов. Предварительное сокращение цвета выполняет Median Cut, затем компоненты выбираются из шкалы DAC. Для дизеринга выбирается одиночный цвет или пара 50/50 с малой добавочной стоимостью контраста пары. Выбор пока основан на усреднении RGB. Фильтр применяется после выбора, результат ещё не оптимизирован под выход NTSC. Полосы имеют ширину 1 пиксель, шахматка период 2×2. Фаза привязана к изображению.

| Объект | Палитра с прозрачным | Тайлы без дизеринга | Полосы | Шахматка |
|---|---|---|---|---|
| AWAC | 11 | 311 | 310 | 310 |
| TANK1 кадр 4 | 15 | 244 | 245 | 245 |
| F217 | 11 | 143 | 151 | 150 |

Для каждого варианта реально сформированы patterns.bin (4 bpp), map.bin (VDP-слова с отражениями) и palette.bin (16 слов CRAM). Все тайлы обратно восстановлены из этих данных и сравнены с вариантом до упаковки. Файлы служат промежуточным форматом. Карты объектов ещё требуется разбить на аппаратные спрайты и учесть лимиты строк. Палитры отдельных объектов нужно согласовать с уровнем, игроком и HUD.

Все варианты используют ту же палитру внутри одной строки сравнения. Поэтому разница показывает эффект узора, а не замену набора цветов между колонками. Числа расхода записаны в output/report.json. Графика и промежуточные бинарные ресурсы локальные. В репозитории сохраняются скрипты и отчёт.

Визуальный результат предварительный. На воде дизеринг смягчает границы оттенков в NTSC-модели. На крыше башни полосы дают цветной артефакт. Для итоговой версии нужен подбор узора по участкам и проверка в движении. Тень башни в этом опыте сохраняет исходную непрозрачную графику. Эффект полупрозрачной тени этим опытом ещё не реализован.

## Выбранный вариант и следующий этап

Пользователь выбрал шахматку. У AWAC дополнительно закреплены CRAM-цвета с компонентами RGB3 (7,0,0), (7,4,0), (7,6,1), чтобы малочисленные пиксели пожара сохранили красные, оранжевые и жёлтые оттенки. Проверка требует красные и жёлтые пиксели в результате. Их количества в текущем кадре 69 и 49. Всего 11 цветов с прозрачным.

Исправлено совпадение имени Python-модуля preview.py с именем собранной библиотеки preview.so. Библиотека теперь называется ntsc_filter.so и не перекрывает импорт Python.

build_native_ground.py строит полный шахматный вариант местности и упаковывает его в сетку Jungle 20×28 блоков по 32×16 ячеек VDP. Уникальных паттернов 449, их графика 14 368 байт. Уникальных блоков карты 202. Таблица указателей, описатели и карты блоков занимают 215 552 байта. Базовый адрес по умолчанию 0x300000 выбран для сборки кандидата и должен согласовываться со всей ROM-компоновкой.

При отражении DOS-тайлов фаза шахматки компенсируется. Проверка всех встречающихся комбинаций тайла и отражений сравнивает результат с дизерингом уже отражённого исходного изображения. Все 286 720 слов карты затем проверены через нативную адресацию блоков. Описатели используют шаблон местности второго уровня и несжатые карты слов. Подключение тайлсета, палитры, VRAM и регистрация уровня в игре ещё нужны. Совместное использование палитр всей сцены пока не проверено.

Запуск — `python strike_work/dos/color_experiment/build_native_ground.py strikehd/rom/jungle_strike.bin`.
