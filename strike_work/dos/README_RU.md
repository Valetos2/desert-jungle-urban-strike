# Jungle Strike DOS: первый разбор, 16 ноября 2026

Это исследовательский пакет; новых Genesis ROM/IPS в нём нет. Последняя принятая пользователем сборка — Strike_Checkpoint_12.zip. Её код и ROM не менялись.

## Что получилось

Из комбинированного CD BIN/CUE извлечено 108 файлов. Jungle и Desert имеют отдельные EXE и DAT. Маленький JUNGLE.EXE — загрузчик: настоящий исполняемый файл и ресурсы хранятся в JUNGLE.DAT.

Распаковщик JUNGLE.DAT восстановлен по коду DOS-загрузчика. Распакованы все 364 ресурса, суммарно 10 098 665 байт. Для каждого совпал заявленный размер, округлённый до 16-байтового параграфа; каждый упакованный поток использован полностью. Это проверка структуры декодирования, а не проверка исполнения игры в DOS.

Десятая миссия представлена LEVELA, MAP10, BLOCKS10, DASHMAPA и связанными ресурсами. LEVELA содержит ссылки на map10/blocks10, icebergs, awac, frigate, radar, gatgun, boatpt, subspry, subtur, aaa, zsu, m1, raft, ammo2, life2, tank1, tank2, chopper, reactor, cmndr, goodguy, snowman и графику Fxxx.

Восстановлена графика местности десятой миссии: 128 тайлов по 16×16 пикселей, палитра внутри BLOCKS10. MAP10 содержит 71 680 двухбайтовых ячеек. Раскладка 320×224 ячейки даёт связный мир 5120×3584 пикселя; расположение берегов визуально совпадает с отдельной миниатюрой DASHMAPA. Размер пока подтверждён реконструкцией изображения, а не трассировкой загрузчика миссии.

previews/MAP10_candidate.png — уменьшенная реконструкция местности, без объектов и построек. previews/DASHMAPA.png — исходная миниатюра карты паузы, увеличенная в три раза. Название candidate сохраняет статус пока не проверенных непосредственно в DOS битов отражения и способа адресации.

Пробное сопоставление DOS-тайла с четвёркой Genesis-тайлов не дало однозначного соответствия. Нельзя использовать эти числа как доказательство изменения уровней.

## Форматы

DAT: uint32 LE число записей; с offset16 записи по16 байт: имя8, offset uint32 LE, упакованный/распакованный размер uint16 LE в параграфах. Сжатие: словарь пар символов, затем RLE. Начало словарного блока всегда содержит два байта — количество записей и маркер, даже при нулевом количестве. Подробности в unpack_dat.py.

BLOCKS: заголовок GRAPHICS, секция BLOCKS с количеством тайлов в +40, шириной/высотой в +44/+46; пиксели с +48. PALETTE содержит RGB-компоненты VGA 0..63, данные с +32 относительно метки. MAP — слова LE; в предварительном рендере младшие8 бит — индекс, биты8/9 — отражения по X/Y. Для карт этой выборки индексы укладываются в соответствующий набор.

LEVEL*: таблица локальных смещений, двоичные структуры и хвост ссылок на именованные ресурсы. Смысл полей объектов, координаты, команды сценариев и цели пока не разобраны.

## Подготовка местности для Genesis, 18 ноября 2026

convert_eco_terrain.py преобразует BLOCKS10 и реконструированную MAP10 в паттерны VDP 4 bpp, таблицу 8×8 и палитру CRAM. Из 512 четвертей исходных блоков получилось 344 уникальных паттерна с учётом отражений. Графика занимает 11 008 байт, палитра 32 байта, развёрнутая таблица 640×448 занимает 573 440 байт. Местность использует 14 цветов и помещается в одну строку палитры. RGB округляется из VGA 6 бит на компоненту в Genesis 3 бита, поэтому оттенки требуют визуальной проверки.

Обратное декодирование результата сравнилось с реконструированной DOS-картой по всем 18 350 080 индексам пикселей. Проверены отражения и удаление дубликатов. Статус исходной раскладки MAP10 остаётся предварительным до проверки нативного рендера DOS. Данные ещё не подключены к Genesis-загрузчику, VRAM-база и номер строки палитры задаются на следующем этапе. В полном уровне необходимо также учесть графику объектов и интерфейса.

Запуск из корня проекта — `python strike_work/dos/convert_eco_terrain.py strike_work/dos/unpacked/jungle каталог_вывода`. Исходные ресурсы требуются локально. Численные результаты сохранены в eco_terrain_report.json.

4. После этого проектировать конвертер и экспериментальный ROM, затем переход 9→10→концовка и пароль прежней длины.
