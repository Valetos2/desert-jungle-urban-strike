# Eco Threat · Flight TEST v11

Начните новую игру после сброса. Z в главном меню листает кампании. В Eco Threat кнопка Z по-прежнему завершает текущую тестовую задачу.

- У вертолётных площадок совмещены графика и столкновения по привязке из Snow Fortress. Смещение по X для площадки №28 из GS0 составляет 22 пикселя влево. Исправление применено ко всем перенесённым площадкам.
- Окна башен №38, №41 и №61 переведены на два постоянных зелёных цвета `$0242` и `$0464` из палитры уровня. Смена цветов воды их больше не затрагивает.
- В первой миссии появляются пять зачётных целей по списку DOS: две наземные РЛС и три катера. В этом тесте катера используют графику штатного катера Genesis и короткие тестовые маршруты. Вспомогательные записи размещены по DOS. На карте пять отметок, которые убираются по мере уничтожения целей. Карточка с текстом DOS показывает штатную модель РЛС. Пятая уничтоженная цель открывает вторую миссию. DOS-скрипты Danger Zone и точные маршруты катеров ещё предстоит перенести.
- Добавлены четыре пары айсбергов. У каждого сначала разрушается большая форма, затем меньшая. Коллизии взяты из геометрических полей DOS. Снег и лёд используют штатную палитру ландшафта.
- Дополнительный пролёт от электростанции до опоры подготовлен только в виде двух визуальных вариантов.

## Сборка

Из корня рабочего каталога выполните `python strike_work/eco_flight_v11/build.py`. Нужны ROM v10, NumPy, Pillow и распакованные локальные DOS-ресурсы. Автоматические проверки для Genesis Plus GX запускаются командой `python strike_work/eco_flight_v11/check.py`. Для упаковки передайте путь к v11 BIN скрипту `strike_work/eco_flight_v8/package.py`. IPS применяется к чистому оригиналу с SHA-1 `7a7568e39341b1bb218280ee05c2b37c273317b5`.
