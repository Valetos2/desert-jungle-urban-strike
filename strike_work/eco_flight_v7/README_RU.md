# Eco Threat · Flight TEST v7

После сброса начните новую игру. Сейвы от v6 хранят предыдущую таблицу столкновений и видеопамять.

Исправлены индексы статических объектов, записываемые при отрисовке в таблицу столкновений. Индекс теперь указывает на собственный слот объекта в Eco Threat. Боезапас вертолёта в десятой кампании при выстреле не уменьшается. Прицеливание, интервалы выстрелов и попадания используют штатную логику.

Площадка снова использует графику и цвета Snow Fortress. Заснеженная суша использует исходный узор и строку палитры шестого уровня. Вода сохраняет постоянный цвет фона. Меняется только цвет волн. Пограничные рисунки используют ближайшие оттенки снега из палитры, общей с водой.

Возле трёх точек добавлены существующие объекты Genesis: башня №1, опора №73 и электростанция №82. Башня и электростанция используют штатные варианты руин. Связи с задачами и спаун участников пока не подключены.

В Options → Movie появился Brief 10. Это отдельная последовательность с существующим кадром радиста и новым коротким текстом о ситуации на базе и терминале. Строки переносятся по целым словам и ограничены 30 символами. Это же вступление запускается в начале Eco Threat.

Сборка из корня проекта через python strike_work/eco_flight_v7/build.py и package.py. Требуются собранный v6, материалы локальных сборок v3 и v5, LEVELA для трёх размещений и vasmm68k_mot. IPS применяется к чистому оригинальному ROM с SHA-1 7a7568e39341b1bb218280ee05c2b37c273317b5.
