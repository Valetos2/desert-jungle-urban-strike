# Jungle Strike — Eco Threat Flight TEST v3

Новая сборка для проверки карты, воды, первых объектов и выбора ко-пилота.

## Запуск

Откройте готовый `.bin` и начните новую игру через Campaign. Тест по умолчанию запускает десятую кампанию Eco Threat, внутренний индекс 9. Старые состояния эмулятора не загружайте. Старт — X=3859, Y=40; запас — 99 жизней и 9999 топлива.

## Что изменено

**Карта паузы.** В оригиналах это отдельный подготовленный рисунок, связанный с географией уровня, а не уменьшение игрового экрана в реальном времени. В v2 использовался мой чрезмерно упрощённый обзор местности. В v3 перенесён именно DOS-ресурс DASHMAPA размером 192×136, совпадающим с окном Genesis. Сохранены рисунок берегов, снежных островов, текстура воды и отметка H. Цвета согласованы со штатной палитрой интерфейса. Используется 342 тайла; прежнее ограничение до 29 было решением первого прототипа, а не доказанным аппаратным пределом. Шрифт и рамка проверены в игре.

**Вода.** В Genesis второй кампании движение воды создаёт циклическая перестановка трёх цветов CRAM, а не перерисовка геометрии волн. Проверка 360 кадров показала смену цветов 3–5. После переноса графики в другую палитру прежний обработчик продолжал менять старые цвета. В v3 для Eco Threat он переключает цвета 25–27 — три оттенка, отведённые только воде. Цвета снега и деревьев остаются постоянными. Для штатных кампаний сохранён прежний обработчик. Вывод о работе Genesis подтверждён её кодом и наблюдением CRAM; DOS-обработчик анимации этим тестом не исследовался.

**Первые объекты.** Добавлены 41 дерево F165/F166/F167/F168 и 6 площадок F174. Координаты и высоты взяты из DOS LEVELA. Нативные аналоги установлены сопоставлением статических объектов DOS и Genesis шестой кампании. Используются штатные графика, тени и механизмы столкновений. Списки объектов, память, прямоугольники видимости и маски загрузки графики созданы для нового уровня. Деревья используют зимнюю палитру; графика площадок переназначена в палитру техники, чтобы не окрашиваться цветами анимированной воды. Скрипты шестого уровня с этих объектов не копируются.

**Название.** В основном окне паузы теперь `10.ECO THREAT`; отдельный номер кампании перед названием также записан как 10.

**Ко-пилоты.** В Jungle доступны все пять: начальная маска блокировок очищена, отметки недоступности и отказ выбора отключены. Каждый из пяти вариантов выбран и подтверждён через настоящее меню эмулятора. Это тестовое удобство, действующее и при выборе других кампаний.

## Что ещё не готово

Это по-прежнему незавершённая миссия. Противники, подбираемые предметы, новые DOS-объекты, задания и условия завершения ещё не подключены. Подробные вкладки заданий/схем содержат временные данные шестой кампании. Площадки пока являются объектами местности; завершение миссии и действия базы к ним не привязаны. Первые девять кампаний сохранены, но эта сборка предназначена прежде всего для проверки Eco Threat.

## Что проверить

- Вид подробной карты в паузе, номер перед названием, отсутствие повреждений интерфейса.
- Движение волн, в том числе после возврата из паузы; снег и деревья при этом не должны переливаться цветами воды.
- Деревья и площадки: расположение, тени, перекрытие вертолётом, столкновения, переходы между секторами.
- Выбор любого ко-пилота.

Проверки разработчика: холодный запуск в стартовой точке, углах, центре и около площадки; пауза/возврат; запуск штатных кампаний 2, 6, 9; выбор всех пяти ко-пилотов; наблюдение анимации CRAM; контрольные суммы и точное обратное применение IPS. На реальной консоли эта версия ещё не проверялась.

## IPS

Применять к чистому оригиналу Jungle Strike (USA, Europe), April 1993, 2 МиБ, SHA-1:

`7a7568e39341b1bb218280ee05c2b37c273317b5`

Не применять поверх v1/v2 или других патчей. Результат — линейный ROM 4 МиБ, включающий принятые исправления Jungle v05. В архиве уже есть готовый ROM.

## Сборка

Исходные игровые ресурсы и ROM в GitHub не публикуются. Нужны личные исходные копии и промежуточные данные извлечения предыдущих этапов.

```
python strike_work/eco_flight_v3/object_matches.py
python strike_work/eco_flight_v3/build_terrain.py
python strike_work/eco_flight_v3/build_pause.py
python strike_work/eco_flight_v3/extract_pad.py
python strike_work/eco_flight_v3/build.py
python strike_work/eco_flight_v3/package.py
```

Для `build_terrain.py` нужны stock2_patterns.bin и stock6_patterns.bin, извлечённые процедурой из v2 и помещённые в каталог v3. `extract_pad.py` использует тот же локальный GX с диагностическими экспортами и состояние v2. Вставки из start.asm предыдущей версии и water.asm включены байтами в Python; ассемблер для сборки не обязателен. Сборщик проверяет хеши ROM, свободное место, сохранение первых девяти элементов расширяемых таблиц. `package.py` проверяет заголовок, стандартную контрольную сумму и точное применение IPS к оригиналу.
