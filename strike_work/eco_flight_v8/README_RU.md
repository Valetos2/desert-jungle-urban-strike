# Eco Threat · Flight TEST v8

Начните новую игру после сброса. На главном экране Z выбирает следующую кампанию по кругу от 1 до 10. При удержании кнопки происходит один переход. Номер и название выводит штатное меню. В полёте Z завершает текущую задачу только в Eco Threat.

Тестовый режим во всех кампаниях даёт 99 жизней, 9999 единиц топлива без расхода, боезапас без расхода и защиту от обычного урона по вертолёту. Сценарные условия провала миссий действуют как обычно.

Карта Eco Threat берёт позиции и условия целей из DOS-таблиц DS:3F64 и DS:3F78. Точки рисует штатный код Genesis. Сейчас есть две точки, у Ice Station и электростанции. Они появляются после открытия соответствующих задач. Точку электростанции убирает разрушение самой станции или завершение задачи. До открытия второй задачи карта показывает только отметку игрока. Подвижные цели пока не перенесены. Штатный отрисовщик Genesis умеет брать текущие координаты живого подвижного объекта.

Добавлены три опоры ЛЭП, шесть секций проводов и вход под снежным холмом №6. Для них использованы имеющиеся объекты Snow Fortress. Уничтожение опор отключает связанные провода. Вход появляется после разрушения холма. Люди за входом и остальная логика задания ещё отсутствуют.

Текстура волн взята из второго уровня Genesis. В v7 один цвет контура волн меняется по штатному таймеру Genesis, фон моря использует отдельный постоянный цвет.

Из корня проекта выполнить python strike_work/eco_flight_v8/build.py и package.py. Нужны собранный v7, таблицы из предыдущих сборок, локальные DOS LEVELA и EXECUTABLE и vasmm68k_mot. Ключ --without-campaign-cycle оставляет оригинальный обработчик кнопок главного меню. IPS применяется к чистому ROM с SHA-1 7a7568e39341b1bb218280ee05c2b37c273317b5.
