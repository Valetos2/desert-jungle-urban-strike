# Eco Threat · Flight TEST v12

Начните с аппаратного сброса. Сейвы v11 содержат прежнюю разметку оперативной памяти.

- Катера первой задачи используют корпус штатного катера и верхний спрайт вращающегося радара. Такая же комбинация теперь в карточке задачи. В DOS обработчик карточки при коде FE рисует фон воды из ICONSA и два отдельных спрайта BOATPT и RADAR.
- Все три катера используют маршрут DOS. Его 36 байт целиком совпадают со штатной таблицей Genesis по адресу $1927AA. У каждой из пяти целей восстановлены две команды Danger Zone из LEVELA.
- Катера 12 и 13 при уничтожении переносят ящики 21 и 20 соответственно штатной командой 06/42, затем активируют их. Для этого ящикам выделены длинные подвижные слоты. Катер 23 не оставляет ящика.
- Восемь записей ICEBERGS в LEVELA составляют четыре пары большой/малый. Для всех восьми исправлено число физических объёмов: в v11 ноль перед единственной коробкой заставлял цикл $4271C читать посторонние данные. Размеры и высоты сохранены из THINGS. Точный край при облёте стоит проверить в Kega.
- Изменение освещения башни подготовлено только на внешнем рендере.

Сборка: из корня рабочего каталога выполнить python strike_work/eco_flight_v12/build.py, затем check.py из той же папки (с рабочим каталогом в корне). Требуются локальный образ v11 и распакованные оригинальные DOS-ресурсы. Для упаковки используется strike_work/eco_flight_v8/package.py.
